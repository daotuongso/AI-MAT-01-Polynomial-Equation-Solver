# OUTPUT Contract – MAT-01
Produce equation text, degree, coefficient list (descending), count of distinct roots, total roots including multiplicity equal n, real/complex classification, each root's multiplicity, numerical value, normalized residual and optional exact radicals/expressions when complete. Status `COMPLETED` only if the tool returns successful calculations and arithmetic checks; otherwise `BLOCKED` or `FAILED`. Numerical error residual does not establish exact symbolic proof. Machine-readable JSON output via `--json`. Real-root detection uses SymPy numeric real/imag tolerances: near-real roots are explicitly qualified.
