# Acceptance criteria
AC-01 Accept integer n (1..20) before coefficients.
AC-02 Require exactly n+1 rational real coefficients in descending order with nonzero leading coefficient.
AC-03 Return all complex roots counted with multiplicity n; real values classified.
AC-04 Approximate roots have normalized residual values and explicit precision limitations.
AC-05 Handle linear, distinct real roots, repeated roots and complex roots.
AC-06 Invalid inputs rejected; no silent degree reduction.
AC-07 Self-contained Markdown-first, Read Contract 10, executable CLI, example, manifest and clean extraction tests PASS.
AC-08 Do not self-approve, self-publish, change Github or expand scope.
