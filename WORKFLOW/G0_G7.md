# Controlled Workflow – MAT-01
| Gate | Activity | Output | Stop/QA |
|---|---|---|---|
| G0 | Receive integer degree n | degree register | n 1..20 |
| G1 | Receive n+1 descending coefficients | inputs | no invented defaults |
| G2 | Validate leading coefficient and rational syntax | normalized Poly | bad data => BLOCKED |
| G3 | Decompose polynomial into square-free factors | multiplicity map | preserve degree |
| G4 | Solve factors numerically (and exact small-degree optional) | complex roots + multiplicities | tool errors => FAILED |
| G5 | Evaluate normalized residual and reality classification | verified numerical results | not exact proof |
| G6 | Format equation and results | text/JSON answer | no unrelated tasks |
| G7 | Present results for user review | final response | no self-approval of Skill |

Gates describe one authorized calculation session; user request to solve the entered polynomial covers G0–G7 computation and reporting. The development Pack and operational release remain subject to Owner approval.
